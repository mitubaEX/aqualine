# モバイル操作デモ

- [GIFプレビュー](aqualine-mobile.gif)
- [MP4（高画質・無音）](aqualine-mobile.mp4)

2026-10-29のAquaLineを、MacのChromeで390×844pxのモバイル幅にして操作しました。**デモ専用の空のローカル保存領域・模擬位置・架空の文章だけ**を使用しています。表示名はアプリが生成したテストセッションの匿名名です。

実際のUIの画面キャプチャを7場面・各3秒に編集した21秒のステップ式デモです。連続録画や実時間の応答速度を示す映像ではありません。画面上部のデモ表記と下部の場面字幕は紹介用に加えたもので、アプリ内の機能ではありません。

| 時間 | 内容 |
| --- | --- |
| 0〜3秒 | 橋と海をモチーフにした入口 |
| 3〜6秒 | 乗客確認、開発用テスト入場 |
| 6〜9秒 | 模擬位置で広場に参加 |
| 9〜12秒 | 架空のサンプル文を入力 |
| 12〜15秒 | 投稿がタイムラインに表示 |
| 15〜18秒 | 別のテスト参加者からリアクション・返信操作 |
| 18〜21秒 | 返信が広場に表示 |

ブラウザのタブ・アドレスバー・OS通知・音声は収録していません。実GPS、実ユーザーの投稿、現地での動作確認、一般向けサービスの稼働を示すものではありません。スマートフォン実機での録画でもありません。

MP4はH.264 / yuv420p、390×932px（字幕枠を含む）、24fps、無音。GIFは同じ内容を4fps・128色で軽量化しています。アプリのローカル起動方法と検証限界は[README](../../README.md)を参照してください。
