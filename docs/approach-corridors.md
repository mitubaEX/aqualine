# 進入路の追加（2026-10-31）

アクアラインに入る直前に測位できなくなる問題に対し、川崎浮島JCTからK6川崎線・湾岸線東京側・湾岸線横浜側、木更津側の従来の着岸端点からアクアライン連絡道を、それぞれ道路沿いに約3km追加しました。浮島・金田の接続ランプも含みます。一般道を3km延ばしたり、地域全体を円で許可したりする変更ではありません。

## 形状と出典

**国土地理院ベクトルタイル提供実験の道路データを抽出・切断・丸めてAquaLineが加工作成。国土地理院が作成・保証した入場範囲ではありません。** [提供実験・仕様](https://github.com/gsi-cyberjapan/gsimaps-vector-experiment)、[利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)（PDL1.0、出典と加工の表示）。プロジェクトのライセンスは変更しません。

取得URLは `https://cyberjapandata.gsi.go.jp/xyz/experimental_bvmap/14/{x}/{y}.pbf`。2026-10-31取得、x=14552〜14560、y=6459〜6466のroad layerからmotorway=1を選択しました。LineStringとMultiLineStringを独立した線として扱います。トンネル・高架・ランプも道路形状を保持します。採用形状は `server/approach-roads.ts`。緯度経度は小数7桁に丸め、逆順を含む同一線は重複排除しました。

抽出時の切断境界（経度min、緯度min、経度max、緯度max）は以下です。**この矩形内が許可されるのではなく、矩形で切断した実道路線までの距離を判定します。** 異なるfeature・タイル・分岐間の直線接続は一切追加していません。

## 利用上の限界

中心線まで100m以内・accuracy80m以下、最後の確認から最大60分は変更しません。道路近傍100mには並行一般道・工場・施設の一部も入り得ます。高速道路の利用、アクアラインへの進行、実在位置を証明するものではありません。範囲の端にも100mの丸い端部が付きます。

[首都高速の構造説明](https://www.shutoko.co.jp/activities/database/route/)ではK6の浮島〜殿町付近は上下2層の高架、湾岸線は多摩川・川崎航路トンネル、羽田空港付近は半地下構造です。範囲拡張で測位機会は増えますがGPSや通信の復旧は保証できません。未入場のまま地下に入った場合は依然入場できない場合があります。位置不明・再読み込み・通信復帰で60分を延長せず、精度のよい範囲外確認で失効します。Android実機・実ソフトキーボード・現地GPS・トンネルは未検証です。
