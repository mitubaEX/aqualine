# 橋区間の位置判定補正（2026-10-30）

これは当時の補正記録です。現在のトンネルと進入路は [2026-10-31の拡張](approach-corridors.md) を参照してください。橋形状と判定閾値は維持しています。

橋上で「エリア外」になる報告を調査し、旧4点の橋区間が実際の橋より北へ外れていることを確認しました。全長の違いだけを根拠にはしていません。今回、海ほたる本線へのつなぎから木更津側の橋終端・本線合流点までを修正しました。木更津金田IC全体・一般道・アクアライン連絡道を新たな対象にはしていません。

## 出典・利用条件

**国土地理院ベクトルタイル提供実験の道路データを抽出・丸め・接続してAquaLineが加工作成。国土地理院が作成・保証した入場範囲ではありません。**

- [データ仕様・利用条件](https://github.com/gsi-cyberjapan/gsimaps-vector-experiment)：`experimental_bvmap`、道路layer、motorway=1、幅25mの本線を選択。公開仕様の更新時点は2026年7月1日、取得日は2026年10月30日。
- [国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)：PDL1.0、出典・加工の明記。プロジェクト全体のライセンス変更ではありません。
- [測量成果の利用手続](https://www.gsi.go.jp/LAW/2930-index.html)：地理院地図Vector（試験公開）は測量成果に該当しないコンテンツとして掲載。実験データにも基本測量成果ではない旨が明記されています。標準地図をトレースして配布する代わりに、このVectorデータから定義を作成しました。
- 定義の取得URL形式：`https://cyberjapandata.gsi.go.jp/xyz/experimental_bvmap/14/{x}/{y}.pbf`。対象x=14557〜14560、y=6463〜6465。本線の頂点を選択し緯度経度を小数7桁に丸めました。ランプの全域は追加していません。
- 検証用の地図出典：[地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)。画像は比較のため一時利用し、アプリやリポジトリへ転載していません。個人の測位データは利用していません。

z16のこの緯度では1pxは約1.95m。目視読み取りを±4px（約8m）程度と見積もっています。これは地図自体の位置精度や実GPS誤差を保証するものではありません。標準地図とVectorは同じ機関の資料であり、独立した現地測量ではありません。さらに、定義に採用しなかったVector本線頂点で海ほたる・橋始点・着岸側の接続を検査しています。

一般道の独立検証点はVectorの14/14559/6465、緯度35.4350481・経度139.9129540（road属性 tollSect=0、rdCtg=2、motorway=9）から取得し、範囲外となることを確認します。

橋の両側の海上、木更津側の離れた地点、旧誤端点、修正端点より先を拒否するテストと、距離99.99/100.01/159/161m・accuracy80/81mの境界テストを併用します。100m以内に隣接する一般道などをすべて識別できる設計ではありません。

## 維持する条件と限界

- 道路入場は中心線までの距離≤100mとaccuracy≤80mを独立して判定します。距離50m・accuracy60mでも入場・延長できます。海ほたる単独の特別範囲は従来どおり中心距離＋accuracy≤190m。退出判定は道路距離−accuracy>150mかつ海ほたる中心距離−accuracy>240mを維持します。
- 海ほたる特別範囲の中心・半径、トンネル側の既存3点は変更しません。旧トンネル近似のずれは別課題であり、本修正で全路線が正確になったとはしません。接続は既存の海ほたる範囲内で行います。
- accuracy>80mは距離にかかわらず不確定扱いです。初回12秒測位、再試行UX、測位時刻検査は変更していません。海ほたるの一部でaccuracy80mが入場不可になることもあります。
- 実機GPS・車内・トンネル・現地の成功は未検証。位置自己申告の偽装を防ぐものではありません。
- 再試験は同乗者が安全に操作できる時だけ行ってください。運転中・歩行中の操作はしないでください。

## 距離と精度の分離（2026-10-30 本番反映済み）

ユーザー承認に基づき、道路への入場距離と測位精度を分離しました。`server/domain.ts` の `ENTRY_DISTANCE_METRES`（100）と `MAX_LOCATION_ACCURACY_METRES`（80）で設定できます。退出と海ほたるの定数も同じ場所に明示しています。座標列は前回の補正を維持。環境変数からの動的変更ではなく、変更にはコード検証・再デプロイが必要です。

不確定な測位では新規入場を拒否して再測位を案内し、既存参加券は延長せず期限まで維持します。信頼できる範囲外のみ退出します。道路中心から100m以内でも真の位置が橋外の可能性があり、従来より誤入場の余地が増えます。海ほたる単独の円の判定は不変ですが、重なる道路帯は新しい距離条件の対象です。100m境界の座標テストは浮動小数点の投影誤差を避けて内外1cmで検査しています。
