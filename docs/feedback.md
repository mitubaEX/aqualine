# フィードバック（Googleフォーム）

画面下部の「ご意見・不具合を送る」で、以下の回答用フォームを新しいタブに開きます。

https://docs.google.com/forms/d/e/1FAIpQLSeIQZRPsiWgp8Za9JuBKBd2PZrdGhycglW76tJvMKEjOBGwZA/viewform

参加券・現在地をURLへ追加せず、`noopener noreferrer` と `referrerPolicy="no-referrer"` を指定します。フォームへの回答はAquaLineの広場には表示されません。Google側の取り扱い・保存となり、アプリの投稿削除期限や旧案の30日清掃は適用しません。氏名・連絡先を入力せず、緊急連絡に利用しないでください。運転中・歩行中の操作は禁止です。

運営はフォーム所有者のGoogleアカウントから回答を確認します。引継ぎ時点の設定はメール収集・ログイン必須・回答概要公開がオフ、編集権限は所有者のみです。アプリからこれらの設定を変更したり、回答一覧を公開したりしません。保存期限・通知・削除運用はフォーム所有者側で管理してください。

旧案の独自受付API・管理画面・管理キー方式は本番未公開のまま撤回しました。管理シークレットはCloudflareに設定しません。既存の投稿・通報・参加券の保存領域は変更せず、データの一括削除もしません。

通常投稿の表示と削除対象は24時間、通報内容は30日、参加券は最後の位置確認から60分のままです。公開時に1〜24時間前の未削除投稿が再表示される可能性があります。
